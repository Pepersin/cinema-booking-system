# Cinema Booking System

**Проектирование информационной системы онлайн-бронирования билетов в кинотеатр**

## О проекте

Учебный проект информационной системы для автоматизации процессов бронирования билетов в кинотеатр.

В рамках проекта проведён анализ предметной области, определены требования к системе, разработаны пользовательские сценарии, UML-диаграммы и проектная архитектура.

## Цель проекта

Спроектировать информационную систему, позволяющую автоматизировать взаимодействие посетителей с кинотеатром, упростить процесс выбора сеансов и бронирования мест.

## Основные функции системы

В проектной документации предусмотрены:

- Просмотр каталога фильмов и расписания сеансов.
- Просмотр информации о фильмах.
- Выбор сеанса и доступных мест.
- Оформление бронирования.
- Управление фильмами и расписанием.
- Управление бронированиями.
- Разграничение прав пользователей.

## Аналитическая часть

В рамках учебного проекта подготовлены следующие материалы:

- Анализ предметной области.
- Определение заинтересованных сторон.
- Функциональные и нефункциональные требования.
- Спецификация требований к программному обеспечению (SRS).
- UML Use Case Diagram.
- UML Sequence Diagram.
- Проектирование пользовательского интерфейса.
- Проектирование архитектуры системы.
- Оценка трудоёмкости и планирование разработки.
