# Cinema Booking System

**Проектирование информационной системы онлайн-бронирования билетов в кинотеатр**

## О проекте

Учебный проект информационной системы для автоматизации процесса бронирования билетов в кинотеатр.

Проект включает анализ предметной области, формирование требований, моделирование пользовательских сценариев, проектирование архитектуры и разработку веб-прототипа.

## Цель проекта

Разработать проектное решение, позволяющее автоматизировать основные процессы взаимодействия посетителей с кинотеатром: просмотр репертуара, выбор сеанса, выбор мест и оформление бронирования.

## Основные функции системы

В проектной документации предусмотрены:

- Просмотр каталога фильмов и расписания сеансов.
- Просмотр информации о фильмах.
- Выбор сеанса и доступных мест.
- Бронирование билетов.
- Управление информацией о фильмах и сеансах.
- Управление бронированиями.
- Разграничение пользовательских ролей.

## Аналитическая часть

В рамках учебного проекта подготовлены:

- Анализ предметной области.
- Описание заинтересованных сторон.
- Функциональные и нефункциональные требования.
- Спецификация требований к программному обеспечению (SRS).
- UML Use Case Diagram.
- Диаграммы последовательности.
- Проектирование пользовательского интерфейса.
- Проектирование архитектуры системы.
- Оценка трудоёмкости и планирование разработки.

## Программный прототип

В рамках учебной работы также подготовлен веб-прототип с использованием:

- Python.
- Flask.
- HTML/CSS.
- JavaScript.
- JSON для хранения демонстрационных данных.

Прототип включает отдельные функции каталога фильмов, выбора мест, избранного и обработки бронирований.

Проектируемая архитектура и фактическая реализация прототипа различаются. Не все функции, описанные в требованиях, реализованы полностью.

## Документация

В репозиторий будут добавлены спецификация требований, диаграммы, архитектурные материалы и исходный код прототипа.

## Статус проекта

Учебный проект, разработанный в рамках дисциплины «Программная инженерия» в НГТУ.

Материалы репозитория включают проектную документацию и демонстрационную реализацию отдельных функций системы.
